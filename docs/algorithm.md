# 算法约定与手工向量

本文给出本项目使用的全部算法约定。作业要求各组使用相同的算法流程和转换单元（替换盒、列混淆矩阵等），所以与其他小组互测之前，请先逐条核对本文的参数；一旦约定不同，再正确的实现也会得到不同的密文。

## 来源与标识

- 算法标准：教材《密码编码学与网络安全——原理与实践（第 8 版）》附录 D“简化 AES”（S-AES）。
- 协议标识：`saes-appendix-d-v1`，写在交换文件里，用于快速判断双方约定是否一致（它是本项目用于核对的标识，不是外部官方编号）。
- 参数规模：分组 16 位，密钥 16 位，共 3 个轮密钥（K₀、K₁、K₂），两轮。

## 数据表示（图 D.2）

16 位值的**最高位是 b₀**，十六进制写法与二进制一致：`0x6F6B = 0110 1111 0110 1011`。按顺序每 4 位一个半字节（nibble）：

```text
N0 = b0..b3    N1 = b4..b7    N2 = b8..b11    N3 = b12..b15
```

状态矩阵**按列排列**（教材图 D.2）：前 8 位占第一列、后 8 位占第二列。

```text
[[S0,0, S0,1],     [[N0, N2],
 [S1,0, S1,1]]  =   [N1, N3]]
```

所以十六进制写成 `N0 N1 N2 N3` 四个字符时，`8A1C` 对应矩阵 `[[8, 1], [A, C]]`。密钥同样如此：`K = w₀ w₁`，w₀ 是第一个字节（左边 8 位）。

## 固定参数

**S 盒（表 D.1(a)）**：输入半字节的左 2 位是行号、右 2 位是列号。

| 行＼列 | 00 | 01 | 10 | 11 |
| --- | --- | --- | --- | --- |
| 00 | 9 | 4 | A | B |
| 01 | D | 1 | 8 | 5 |
| 10 | 6 | 2 | 0 | 3 |
| 11 | C | E | F | 7 |

即 `S = [9, 4, A, B, D, 1, 8, 5, 6, 2, 0, 3, C, E, F, 7]`（下标是 4 位输入）。

**逆 S 盒（表 D.1(b)）**：

| 行＼列 | 00 | 01 | 10 | 11 |
| --- | --- | --- | --- | --- |
| 00 | A | 5 | 9 | B |
| 01 | 1 | 7 | 8 | F |
| 10 | 6 | 0 | 2 | 3 |
| 11 | C | 4 | D | E |

**GF(2⁴)**：4 位数 `a₀a₁a₂a₃` 表示多项式 `a₀x³ + a₁x² + a₂x + a₃`，运算模 `x⁴ + x + 1`（`0b10011`）。加法是按位异或；乘法见下例（教材附件 D.1）：`4·C = x²·(x³+x²) = x⁵+x⁴ ≡ x²+1 = 5`。

**列混淆矩阵**：`M = [[1, 4], [4, 1]]`，逆矩阵 `M⁻¹ = [[9, 2], [2, 9]]`（均在 GF(2⁴) 上）。验证：`9 ⊕ 2·4 = 9 ⊕ 8 = 1`，`9·4 ⊕ 2 = 2 ⊕ 2 = 0`，所以 `M⁻¹·M = I`。

**轮常数**：`RC[i] = xⁱ⁺²`，`RCON(1) = 1000 0000 = 0x80`，`RCON(2) = x⁴ mod (x⁴+x+1) = x+1 = 0011 → 0011 0000 = 0x30`。

## 四个变换

| 缩写 | 名称 | 定义 |
| --- | --- | --- |
| A_K | 轮密钥加 | 状态与 16 位轮密钥逐位异或（自身的逆） |
| NS | 半字节代替 | 四个半字节分别查 S 盒 |
| SR | 行移位 | 第一行不变，第二行的两个半字节互换：`N0 N1 N2 N3 → N0 N3 N2 N1`（自身的逆） |
| MC | 列混淆 | `M × 状态`：`S′₀,₀ = S₀,₀ ⊕ 4·S₁,₀`，`S′₁,₀ = 4·S₀,₀ ⊕ S₁,₀`，`S′₀,₁ = S₀,₁ ⊕ 4·S₁,₁`，`S′₁,₁ = 4·S₀,₁ ⊕ S₁,₁` |

逆变换：INS（查逆 S 盒）、ISR（同 SR）、IMC（左乘 `M⁻¹`）。

列混淆的位运算形式（附件 D.2，b₀ 是最高位）：

```text
S′0,0 = [b0⊕b6,  b1⊕b4⊕b7,  b2⊕b4⊕b5,  b3⊕b5]
S′1,0 = [b2⊕b4,  b0⊕b3⊕b5,  b0⊕b1⊕b6,  b1⊕b7]
S′0,1 = [b8⊕b14, b9⊕b12⊕b15, b10⊕b12⊕b13, b11⊕b13]
S′1,1 = [b10⊕b12, b8⊕b11⊕b13, b8⊕b9⊕b14, b9⊕b15]
```

## 密钥扩展（图 D.5）

密钥 16 位拆成两个 8 位字 `w₀ w₁`，扩展出 `w₂…w₅`：

```text
g(w)  = SubNib(RotNib(w)) ⊕ RCON(i)     RotNib 交换高低半字节，SubNib 对两个半字节分别查 S 盒
w₂ = w₀ ⊕ g(w₁)   （用 RCON(1)）
w₃ = w₂ ⊕ w₁
w₄ = w₂ ⊕ g(w₃)   （用 RCON(2)）
w₅ = w₄ ⊕ w₃
K₀ = w₀w₁，K₁ = w₂w₃，K₂ = w₄w₅
```

## 加密与解密流程（图 D.1）

```text
加密：C = A_K2 ∘ SR ∘ NS ∘ A_K1 ∘ MC ∘ SR ∘ NS ∘ A_K0 (P)
        第 0 轮：A_K0；第 1 轮：NS SR MC A_K1；第 2 轮：NS SR A_K2（没有 MC）
解密：P = A_K0 ∘ INS ∘ ISR ∘ IMC ∘ A_K1 ∘ INS ∘ ISR ∘ A_K2 (C)
```

两个函数调用都从右向左执行。解密用 INS∘ISR 与 ISR∘INS 等价（二者可交换）。教材 D.5 还证明了 `IMC(A_K1(N)) = A_{IMC(K1)}(IMC(N))`，因此可以得到与加密同构的“等价逆算法”，本项目的实现 C 就用它解密。

## 可手工复核的例子

### 教材 D.3：密钥 2D55

`w₀ = 2D = 0010 1101`，`w₁ = 55 = 0101 0101`。

- `w₂ = 2D ⊕ 80 ⊕ SubNib(55) = 0010 1101 ⊕ 1000 0000 ⊕ 0001 0001 = 1011 1100 = BC`
- `w₃ = BC ⊕ 55 = 1110 1001 = E9`
- `w₄ = BC ⊕ 30 ⊕ SubNib(RotNib(E9) = 9E) = 1011 1100 ⊕ 0011 0000 ⊕ 0010 1111 = 1010 0011 = A3`
- `w₅ = A3 ⊕ E9 = 0100 1010 = 4A`

轮密钥 K₀ = `2D55`，K₁ = `BCE9`，K₂ = `A34A`。

### 教材 D.2.1–D.2.4 是同一次加密：P = A749，K = 2D55

教材里四个变换示例的输入、输出恰好前后衔接，网页第 1 关“载入示例”可以一键复现：

| 步骤 | 状态矩阵 | 十六进制 | 教材位置 |
| --- | --- | --- | --- |
| 输入 | [[A,4],[7,9]] | `A749` | D.2.1 的状态 |
| A_K0（⊕ 2D55） | [[8,1],[A,C]] | `8A1C` | D.2.1 |
| NS | [[6,4],[0,C]] | `604C` | D.2.2 |
| SR | [[6,4],[C,0]] | `6C40` | D.2.3 |
| MC | [[3,4],[7,3]] | `3743` | D.2.4 |
| A_K1（⊕ BCE9） | | `8BAA` | |
| NS | | `6300` | |
| SR | | `6003` | |
| A_K2（⊕ A34A） | | **`C349`** | 密文 |

### 完整手算：P = 6F6B，K = A73B → C = 0738

密钥扩展：`w₀ = A7`，`w₁ = 3B`。`RotNib(3B) = B3`，`SubNib(B3) = 3B`（S(B)=3，S(3)=B）；`w₂ = A7 ⊕ 80 ⊕ 3B = 1C`；`w₃ = 1C ⊕ 3B = 27`；`RotNib(27) = 72`，`SubNib(72) = 5A`（S(7)=5，S(2)=A）；`w₄ = 1C ⊕ 30 ⊕ 5A = 76`；`w₅ = 76 ⊕ 27 = 51`。所以 K₀ = `A73B`，K₁ = `1C27`，K₂ = `7651`。

| 步骤 | 计算 | 状态 |
| --- | --- | --- |
| 输入 | | `6F6B` |
| A_K0 | `6F6B ⊕ A73B` | `C850` |
| NS | N = C 8 5 0 → S(C)=C，S(8)=6，S(5)=1，S(0)=9 | `C619` |
| SR | 第二行（N1=6，N3=9）互换 | `C916` |
| MC | 矩阵 [[C,1],[9,6]]：`S′₀,₀ = C ⊕ 4·9 = C ⊕ 2 = E`；`S′₁,₀ = 4·C ⊕ 9 = 5 ⊕ 9 = C`；`S′₀,₁ = 1 ⊕ 4·6 = 1 ⊕ B = A`；`S′₁,₁ = 4·1 ⊕ 6 = 4 ⊕ 6 = 2` | `ECA2` |
| A_K1 | `ECA2 ⊕ 1C27` | `F085` |
| NS | S(F)=7，S(0)=9，S(8)=6，S(5)=1 | `7961` |
| SR | 第二行（N1=9，N3=1）互换 | `7169` |
| A_K2 | `7169 ⊕ 7651` | **`0738`** |

其中 `4·9 = x²(x³+1) = x⁵+x² ≡ x = 2`，`4·6 = x²(x²+x) = x⁴+x³ ≡ x³+x+1 = B`（模 x⁴+x+1）。解密把状态序列反向走一遍：`0738 → 7169 → 7961 → F085 → ECA2 → C916 → C619 → C850 → 6F6B`。

## 扩展功能的约定

以下约定教材没有规定，是本项目自行选择的；与其他小组互测这些功能前必须先核对。

**第 3 关 字符串**

- 编码：ASCII 字符与其 ASCII 编码一致；中文等字符按 UTF-8 转成字节。
- 分组：每 2 字节一个 16 位分组，**高字节在前**（`"AB"` = `0x4142`）。逐组独立加密（ECB）。
- 填充：奇数字节时补齐到偶数。`zero`（默认）补一个 `0x00`，解密时去掉**至多一个**末尾的 `0x00`；偶数长度时与不填充相同。`pkcs7`：总是补 1 或 2 个字节（值等于补的字节数）。`none`：要求偶数字节。
- 密文展示：十六进制、Base64，以及把不可打印字节显示为 `·` 的“乱码字符串”视图（仅用于观察，传递请用十六进制或 Base64）。

**第 4 关 多重加密**

- 双重：`K = K1 ‖ K2`（K1 在高 16 位），`C = E_K2( E_K1( P ) )`，`P = D_K1( D_K2( C ) )`。
- 三重（EDE）：32 位密钥 `K1 ‖ K2`：`C = E_K1( D_K2( E_K1( P ) ) )`；48 位密钥 `K1 ‖ K2 ‖ K3`：`C = E_K3( D_K2( E_K1( P ) ) )`。解密分别为 `P = D_K1( E_K2( D_K1( C ) ) )`、`P = D_K1( E_K2( D_K3( C ) ) )`。
- 中间相遇攻击：用第一对明密文建立 `E_K1(P) → K1` 的表（2¹⁶ 项），枚举 K2 计算 `D_K2(C)` 查表得到候选 `(K1, K2)`，再用其余明密文对筛选。

**第 5 关 CBC**

- `C₀ = IV`，`Cᵢ = E_K( Pᵢ ⊕ Cᵢ₋₁ )`；解密 `Pᵢ = D_K( Cᵢ ) ⊕ Cᵢ₋₁`。IV 16 位，随机生成，双方必须使用同一个值（不需要保密）。
- “传输包”格式：`IV ‖ C₁ ‖ C₂ ‖ …`，每个分组 4 个十六进制字符。
- 长消息按第 3 关的方式转成字节、填充（默认补 `0x00`；也可选 PKCS#7）。

## 交叉测试交换格式

**JSON 文件**（`schema` = `saes-cross-test-v1`），网页“生成交换文件”或 `python -m saes export` 生成：

```json
{
  "schema": "saes-cross-test-v1",
  "spec_id": "saes-appendix-d-v1",
  "conventions": {"state_layout": "按列排列：N0=b0..b3, ...", "sbox": "9 4 A B D 1 8 5 6 2 0 3 C E F 7 ...", "...": "..."},
  "vectors": [
    {"plaintext": "0110111101101011", "key": "1010011100111011", "ciphertext": "0000011100111000",
     "plaintext_hex": "6F6B", "key_hex": "A73B", "ciphertext_hex": "0738"}
  ]
}
```

核验时读取 `plaintext`、`key`、`ciphertext`（16 位二进制或 4 位十六进制均可）；`spec_id` 不一致会被拒绝。

**纯文本**：每行「明文 密钥 密文」，二进制或十六进制，空白 / 逗号 / 分号分隔，`#` 之后是注释：

```text
6F6B A73B 0738
0000 A73B 90A6   # 全零明文
```

见 [examples/](../examples/)。

**互测前的核对清单**（任何一条不同，密文就会不同）：

1. 位序：b₀ 是最高位；十六进制写法与二进制一致。
2. 半字节排列：`N0 N1 N2 N3` 依次是第 0 列的两行、第 1 列的两行（**按列**，不是按行）。
3. S 盒：`9 4 A B D 1 8 5 6 2 0 3 C E F 7`；左 2 位选行、右 2 位选列。
4. 行移位：交换第二行的两个半字节，即 `N1 ↔ N3`。
5. 列混淆矩阵 `[[1,4],[4,1]]`，GF(2⁴) 模 `x⁴+x+1`；**第 2 轮没有列混淆**。
6. 密钥扩展：`w₂ = w₀ ⊕ 80 ⊕ SubNib(RotNib(w₁))`、`w₄ = w₂ ⊕ 30 ⊕ SubNib(RotNib(w₃))`。
7. 加密在第 0 轮先做一次 A_K0，每轮的轮密钥顺序是 K₀、K₁、K₂。

用 [已知向量](../examples/vectors.txt)（`6F6B / A73B → 0738`）和教材连贯示例（`A749 / 2D55 → C349`）先对一遍，再扩大到更多向量。

## 本项目的三种实现

为了在一个人完成时也能做交叉测试，项目里有三份结构不同的独立实现（A 整数查表、B 0/1 字符串、C GF 多项式矩阵 + 等价逆算法），区别和全空间互验结果见[个人模拟记录](personal-simulation-report.md)。它们由同一人编写，能发现实现错误，但不能替代真人互测。
