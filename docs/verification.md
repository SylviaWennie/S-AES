## 验证中发现并修复的问题

- 服务端拒绝请求（403 / 400）时没有先读掉请求体，Windows 上连接会被重置，客户端偶尔收不到错误响应。完整测试跑出一次 `ConnectionAbortedError` 才暴露；现在拒绝前会先读掉并丢弃请求体，并增加了重复 40 次的回归测试。
- 浏览器检查发现：新增的 `figures.js` 没有加入静态文件白名单；传输动画场景返回的对象形状与播放器不匹配而显示 `undefined`；核验结果末尾会显示字面量 `null`；缺少 favicon 导致控制台 404。均已修复，检查项里都有对应断言。
- 行尾：Windows 下用 Python 文本模式改写文件会引入 CRLF，已统一为 LF（`.gitattributes` 也做了约束）。
