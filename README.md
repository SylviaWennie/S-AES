# S-AES · 信息安全实验台

信息安全导论 **作业 2：S-AES 算法实现**。按教材《密码编码学与网络安全》附录 D 实现简化 AES（16 位分组、16 位密钥、两轮），用网页 GUI **复刻教材图 D.1–D.5 的分步图解**，覆盖作业要求的五关；一个人也能在本机完成组内测试、组间测试和全部关卡。

**完成情况：已完成第 1–5 关的开发与测试，结果见 [五关测试结果](docs/test-report.md)。** 组内测试用三种结构不同的独立实现（A 整数查表、B 0/1 字符串、C GF 多项式矩阵）在本机模拟，由同一人编写和运行，这部分不是真人跨组测试；在此基础上已与另一小组 [Anxayh/S-AES_Assignment](https://github.com/Anxayh/S-AES_Assignment) 完成**真实组间测试**，详见 [组间测试报告](docs/cross-test-report.md)。

**运行只需要 Python 3.10+，只用标准库，不需要安装任何第三方包。** 服务只监听 `127.0.0.1`，页面不访问外部网络。

```bash
python app.py
```

打开 **http://127.0.0.1:8766**。端口冲突时用 `python app.py --port 8767`；在终端按 `Ctrl+C` 退出。Windows 也可以把 `python` 换成 `py -3`。

网页上的“**一键闯关**”会实际运行五关自检（教材示例、已知向量、固定种子的随机数据、三种实现互相核对），当前 5/5 通过。

## 快速核验

```bash
python -m unittest discover -v                      # 全部测试（约 1 分钟，含全空间对照）
python -m saes encrypt 6F6B A73B                    # → 0738
python -m saes decrypt 0738 A73B                    # → 6F6B
python -m saes verify examples/vectors.txt          # 核验三列文本向量（含教材连贯示例 A749 / 2D55 → C349）
python -m saes mitm examples/mitm-pairs.txt         # 中间相遇攻击，找回 2D55A73B
python -m saes selftest                             # 五关自检
node scripts/check_ui.mjs                           # 浏览器端到端检查并截图（需要 Chrome / Edge 与 Node 22+）
```

固定向量：`P = 6F6B`，`K = A73B`，轮密钥 `A73B / 1C27 / 7651`，每步状态 `6F6B → C850 → C619 → C916 → ECA2 → F085 → 7961 → 7169 → 0738`。教材 D.2.1–D.2.4 的四个示例恰好是 `P = A749`、`K = 2D55` 这一次加密的前四步（页面“载入示例”可复现）。

## 说明

S-AES 是面向教学的算法，**不是安全的加密算法**：16 位密钥只有 65536 种，可以瞬间穷举。本实验用于理解 AES 的结构与操作、互操作验证以及多重加密和工作模式，不要用它保护真实数据。
